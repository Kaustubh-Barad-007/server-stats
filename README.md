# Server Stats Script

A simple script to check basic server performance metrics.

## What It Shows

* CPU Usage
* Memory Usage (Free vs Used)
* Disk Usage (Free vs Used)
* Top 5 CPU Processes
* Top 5 Memory Processes
* System Info (OS, Uptime, Logged Users, Failed Logins)

## How to Run (VS Code + Windows WSL)

1. Open your VS Code terminal (select **WSL**).
2. Run this command:

```bash
sh server-stats.sh
```
